# MyAnimeLogs API Tests

このディレクトリには、MyAnimeLogs API のテストファイルが含まれています。

## 📁 ファイル構成

### `test.http`

- **基本版 API テスト**: 固定トークンを使用したテストケース
- **用途**: 手動で JWT トークンをコピー&ペーストして使用
- **対象**: 全ての認証・ユーザー管理 API

### `test-dynamic.http`

- **動的版 API テスト**: レスポンスからトークンを自動取得
- **用途**: ログイン後に自動でトークンを使用するテスト
- **対象**: 認証フローを含む包括的なテスト

### `http-client.env.json`

- **環境設定ファイル**: 開発・ステージング・本番環境の設定
- **用途**: VS Code REST Client の環境切り替え
- **設定**: ベース URL、コンテンツタイプなど

## 🚀 使用方法

### 前提条件

1. **VS Code REST Client 拡張機能**をインストール

   ```
   Name: REST Client
   Id: humao.rest-client
   ```

2. **バックエンドサーバー**が起動していること

   ```bash
   # Docker Composeの場合
   docker compose up backend

   # ローカル実行の場合
   cd backend && go run cmd/server/main.go
   ```

### テスト実行手順

#### 推奨実行順序

1. **セットアップ**: ユーザー登録とログイン（テスト 1-2）
2. **基本機能**: プロフィール管理（テスト 3-7）
3. **アニメ管理**: 一覧・詳細・検索（テスト 22-28）
4. **お気に入り管理**: 登録・更新・削除（テスト 29-35）
5. **視聴進捗**: エピソード視聴状態（テスト 36-37）
6. **評価システム**: 評価登録・更新・削除（テスト 38-40）
7. **履歴・統計**: 視聴履歴・予定リスト（テスト 41-43）
8. **エラーケース**: 各種エラーパターン（テスト 44-47）

#### 実行方法

1. `test.http`ファイルを開く
2. 「テストユーザー登録」→「ログイン」の順で実行
3. その後のテストで自動的にトークンが使用される
4. 順番に実行するか、個別にテスト可能

#### 注意事項

- **データベース状態**: テストはアニメ ID 1, 2 が存在することを前提
- **実行順序**: お気に入り関連テストは順序が重要
- **トークン**: ログイン後 24 時間有効

### 環境切り替え

- VS Code の下部ステータスバーで環境を選択
- `development` / `staging` / `production`

## 📝 注意事項

- **トークンの有効期限**: JWT トークンは 24 時間で期限切れ
- **レート制限**: 1 分間に 100 リクエストまで
- **テストデータ**: 開発環境でのみテストデータを作成
- **環境変数**: 各環境の設定は`http-client.env.json`で管理
- **画像アップロード**: REST Client ではファイルアップロードのテストが制限されるため、cURL または Postman の使用を推奨

### 画像アップロード API のテスト方法

REST Client ではファイルアップロードのテストが困難なため、以下の方法を推奨します：

#### cURL でのテスト

```bash
# 画像アップロード
curl -X POST http://localhost:8080/api/users/me/icon \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "icon=@/path/to/image.jpg"

# 画像削除
curl -X DELETE http://localhost:8080/api/users/me/icon \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### 制限事項

- **最大ファイルサイズ**: 5MB
- **許可形式**: JPEG, PNG, GIF, WebP
- **認証**: JWT トークン必須

# MyAnimeLogs API Tests

このディレクトリには、MyAnimeLogs APIのテストファイルが含まれています。

## 📁 ファイル構成

### `test.http`
- **基本版APIテスト**: 固定トークンを使用したテストケース
- **用途**: 手動でJWTトークンをコピー&ペーストして使用
- **対象**: 全ての認証・ユーザー管理API

### `test-dynamic.http`
- **動的版APIテスト**: レスポンスからトークンを自動取得
- **用途**: ログイン後に自動でトークンを使用するテスト
- **対象**: 認証フローを含む包括的なテスト

### `http-client.env.json`
- **環境設定ファイル**: 開発・ステージング・本番環境の設定
- **用途**: VS Code REST Clientの環境切り替え
- **設定**: ベースURL、コンテンツタイプなど

## 🚀 使用方法

### 前提条件
1. **VS Code REST Client拡張機能**をインストール
   ```
   Name: REST Client
   Id: humao.rest-client
   ```

2. **バックエンドサーバー**が起動していること
   ```bash
   # Docker Composeの場合
   docker compose up backend
   
   # ローカル実行の場合
   cd backend && go run cmd/server/main.go
   ```

### テスト実行手順

#### 基本版（test.http）
1. `test.http`ファイルを開く
2. 「新規ユーザー登録」→「ログイン」の順で実行
3. ログインレスポンスから`access_token`をコピー
4. 他のテストケースのAuthorizationヘッダーに貼り付け
5. 各リクエストの「**Send Request**」をクリック

#### 動的版（test-dynamic.http）
1. `test-dynamic.http`ファイルを開く
2. 「テストユーザー登録」→「ログイン」を実行
3. その後のテストで自動的にトークンが使用される
4. 順番に実行するか、個別にテスト可能

### 環境切り替え
- VS Codeの下部ステータスバーで環境を選択
- `development` / `staging` / `production`

## 📝 注意事項

- **トークンの有効期限**: JWTトークンは24時間で期限切れ
- **レート制限**: 1分間に100リクエストまで
- **テストデータ**: 開発環境でのみテストデータを作成
- **環境変数**: 各環境の設定は`http-client.env.json`で管理
